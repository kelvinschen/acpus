Acpus

Every run is an opus.

A runtime-driven workflow orchestrator for ACP agents. Plan a spec, then conduct the run.

GETTING STARTEDQuick Start

01

Install

Install the CLI globally.

npm install -g acpus

02

Plan the workflow

Validate the spec and preview the compiled execution plan — stages, lanes, agent calls — in one step.

acpus plan my-workflow.workflow.spec.json

03

Run the workflow

Execute the spec end-to-end. Acpus conducts each stage, fans out lanes in parallel, and records every attempt.

acpus run my-workflow.workflow.spec.json
