# Acpus Roadmap Index

This directory tracks active Acpus plans, goal records, backlog, and capability
gaps. Lasting product contracts that survive implementation changes live in
`specs/`; current mechanics live in code and executable interfaces. Completed
plans and previous implementations remain available in Git history and release
tags; they are not retained in the current documentation tree.

## Writing Conventions

- Write future plans, goal records, and capability gaps. Delete a roadmap record
  after implementation; move only its qualifying lasting contract into the
  owning Spec.
- Do not use RFC 2119 normative verbs as constraints; those are reserved for
  specs. Use descriptive wording such as "plan", "goal", "gap", "candidate",
  and "TBD" here.
