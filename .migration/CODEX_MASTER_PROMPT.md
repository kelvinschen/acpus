# Codex 主控 Prompt

把下面文本作为每个模块开头的通用约束，然后追加具体模块文件内容。

```text
你正在 kelvinschen/acpus 仓库的 next/rust-port 分支工作。
目标是将当前 Rust port 按 Rust-first 架构完整迁移，但本次只执行当前模块。

硬性要求：
1. 只修改当前模块允许修改的文件。若必须越界，先说明原因，并尽量把越界改动限制到 manifest/import/test 修复。
2. 不要提前执行后续模块。
3. 不要删除测试、降低 lint、用 any/unwrap/allow 掩盖问题，除非模块文档明确允许且必须说明。
4. 保持现有功能行为；公共 JSON shape 不能无意变化。
5. 每次修改后运行模块要求的验证命令。
6. 如果验证失败，先修复当前模块引入的问题；如果是 baseline 已有失败，记录并停止，不要扩大改动。
7. 输出最终摘要：修改了什么、运行了哪些命令、哪些通过/失败、后续模块要处理什么。

执行流程：
- 先阅读当前模块文档。
- 运行预检命令。
- 制定最小变更计划。
- 编辑文件。
- 运行验证命令。
- 修复本模块问题。
- 给出简洁完成报告。
```
